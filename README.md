# TIC TAC TOE

A browser-based Tic-Tac-Toe game with multiple play modes and a polished UI.

## Overview

This project is a web app that lets players choose how they want to play:

- VS BOT: play against the computer
- 2 PLAYERS: local multiplayer on the same device
- MULTIPLAYER: online gameplay support

The app is built with HTML, CSS, JavaScript, Express, and Socket.IO.


## Features

- Multiple game modes
- Interactive Tic-Tac-Toe board
- Win detection and game state updates
- Restart flow
- Responsive web interface

## Tech Stack

- Node.js
- Express
- Socket.IO
- HTML
- CSS
- JavaScript

## Repository

This project is hosted as a GitHub repository for the TIC TAC TOE app.

## Notes

The app is designed to be served as a static web project with a lightweight Express server and frontend pages for each gameplay mode.
